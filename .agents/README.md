# 项目经验与技能

通用的研究汇报、研究任务交付和阶段协调技能由 Multica 统一维护，按职责绑定到每位成员。本仓库不复制这些技能，也不提供占位示例技能。

研究发现、方法选择与下游影响先写入已有实验记录；稳定操作经验先更新对应工作流。只有项目独有、经过实际复用、输入输出和失败边界清楚的流程，才建立 `.agents/skills/<skill-name>/SKILL.md`。

新技能说明触发条件、必读材料、执行步骤、验收和失败处理。实际验证成员能发现并读取后才能依赖它；文件存在不等于运行时已经加载。普通规则仍放 [AGENTS.md](../AGENTS.md) 或 [项目文档](../docs/README.md)，不为每次工作增加技能。
