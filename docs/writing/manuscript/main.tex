\section{Introduction}

This section introduces the research problem and explains why it matters.

The opening paragraph should establish context without overstating novelty.

A placeholder reference can be cited with \citet{placeholder2026} while the project replaces the bibliography.

\section{Methods}

This section describes the data, preprocessing, models, experiments, and evaluation protocol.

The methods should be detailed enough for another researcher to reproduce the main results.

\section{Results}

This section reports the main empirical findings.

Each result should connect to a figure, table, or reproducible experiment artifact.

\section{Discussion}

This section interprets the results and explains their limitations.

Separate direct observations from broader implications.

\section{Conclusion}

This section summarizes the main contribution and the most important evidence.

It should avoid introducing new results.
