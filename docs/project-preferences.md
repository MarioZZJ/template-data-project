# 项目稳定偏好

本文件写稳定约定；具体当期授权、预算余额、状态与负责人在Multica，不在这里维护副本。

## 默认协作

研究阶段由普通Research Lead负责，能够自己做或委派。普通子任务auto，关键成果预先指定独立复核，真正需要人类选择的检查点human。阶段完成默认通报，不无条件阻止已授权后继。

在计划与授权范围内实施、检查和合理恢复，不逐步请批。改变问题、样本、主要方法、证据标准、数据权限或资源总额时才集中提交决定。原任务的暂停和特定限制继续有效。

## 数据和资源

资产根、固定输入、数据访问方式与已确认的资源默认值由初始化时填入。未填写的额度表示未授予，不表示无限。每次实际范围从父阶段取得。原始数据不覆盖，中间数据不入Git；封存样本不因工作流恢复而启封。

## 保存与发布

默认允许在已授权阶段内保存范围清楚的本地研究代码／说明checkpoint，遵循本机署名与权限。不默认push、公开数据或发布成果。不能还原实际运行代码时不声称可复现；与任务无关的dirty文件保留。

## 检查与解释

真实数据核对、过程证据与统计诊断随任务风险设置；不以单元测试数量作为研究质量指标。普通成果自检，预定关键成果独立复核。合法零结果及相反结果保留，并记录论证边界。

## 沟通

中文、自然、科学、简洁；解释实际工作、证据、决定及影响。实质审批、阶段／项目完成通过既有飞书技能通知；普通小任务不刷屏。图片是解释辅助，不是交付或推进门槛。
