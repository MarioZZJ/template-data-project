## 环境与资产

| 项目 | 默认约定 | 本项目选择 |
|---|---|---|
| Python | `uv` 与锁文件，`package=false`，外部稳定环境 | 待确认版本与实际依赖 |
| 资产目录 | 可见的 `~/ResearchAssets/<origin仓库名>/`；Windows 使用用户目录下同名目录 | 默认，或记录用户选定的替代磁盘 |
| 执行 | Linux systemd、macOS launchd、Windows 任务计划程序 | 记录本机已实测平台与限制 |
| 数据源 | 只启用实际需要的系统与依赖；MSSQL 为可选依赖 | 待确认 |
| TeX | CTAN `elsarticle`，Harvard author-year | 待确认语言、作者、期刊及文稿阶段 |
| 远程计算 | 登记执行环境与资源边界，不记录凭据 | 无或待确认 |

## 资源与恢复默认值

- 阶段授权明确数据范围、方法、完整计算规模、费用或配额、截止时间、允许恢复次数和必要复核。未明确的高影响边界先集中确认，不自行推定无限授权。
- 在已有授权内完成全量运行与合理恢复，不对每一步较重计算重复请求相同批准。
- 费用、次数和截止时间跨重启保留。通知失败只恢复通知，不重新提交已受理的计算；结果未知时先核对服务端状态。
- 修改研究问题、样本、主要方法、证据标准或资源范围时提交决策。阶段父任务由用户验收；子任务按登记策略自动收尾。
- 不显著或方向相反的有效结果属于研究证据，不因结果方向增加审批或擅自改变设计。

本项目资源默认值及允许恢复方式：待确认。没有此项默认值时，以当前父任务明确授权为准。

## 凭据与数据访问

- 凭据只放系统环境、资产根的本机 `.env`、用户凭据目录或外部密钥系统，不放项目映射、运行记录、文档或 Git。
- BigQuery 使用外部登录状态，查询先 dry run 并设置已授权的最大计费字节限制。
- MSSQL 默认 `Encrypt=yes`、`TrustServerCertificate=no`；改变证书验证必须有相应明确决定。
- Kaggle 等来源按许可和访问规则使用数据，不将 token 写入日志。

## Git 与论文协作

- 分支和 PR 方式：待确认；固定执行代码需要包含实际改动的提交，提交不代表科学结论验收或获得发布授权。
- 显式选择修改和提交范围，保留已有改动；不 force push，不提交凭据或研究数据。
- Multica 承载研究执行及阶段决定；GitHub Issue 可承载附固定正文位置的批注，实际改写通过小 PR。二者互链，不复制实时任务状态。
- 论文只引用选定到 `outputs/` 的正式图表；来源索引保留生成参数、输入、运行和代码版本。
