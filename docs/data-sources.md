## 版本与追溯

- 新数据版本写新目录，固定输入不能原地覆盖。下游引用明确版本或运行编号，不用 `latest`。
- 负责获取或处理的源码用实际 `src/` 路径；尚未实现时标记待建立，不生成空脚本。
- 中间及分析数据位于对应运行的 `data/`；生成关系和实际参数进入运行记录，影响测量或样本的转换进入实验解释。
- 小型人工映射和来源元数据根据角色、敏感性及复现价值决定是否提交；所有原始与中间研究数据留在外部资产。
- 凭据只在系统环境、资产根的本机 `.env`、用户凭据目录或外部密钥系统，不进入本文件、日志、运行参数和 Git。
