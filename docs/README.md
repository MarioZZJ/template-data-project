# 项目文档

## 本目录职责

`docs/` 保存人和 Agent 共用的长期项目事实：仓库结构、数据来源、项目偏好、研究计划、工作流、示例和论文写作。
文档按内容主题组织，不按读者或运行时组织。

## 初始化时需要判断

- 哪些研究事实必须在执行前确认，哪些可以明确标为待确认。
- 数据、方法、计算环境和协作方式分别由哪个权威文件维护。
- 项目是否需要在现有浅层结构上增加实质性主题文档。
- 哪些说明属于稳定工作流，哪些只是一次性记录。

## 推荐建立的项目文件

- `plans/`：研究计划及其重大修订。
- `workflows/`：稳定的数据、实验、执行、写作和协作规则。
- `writing/`：TeX 手稿与写作说明。
- 新文档只在真实项目知识无法由现有权威文件表达时增加。

## 维护规则

- 优先维护少数被 `AGENTS.md` 和目录 README 引用的权威文档。
- 稳定流程变化时更新相应工作流和邻近 README。
- 不写永久迁移说明，除非项目明确需要审计历史。
- 文件名使用 `kebab-case.md`，链接使用仓库相对路径。
