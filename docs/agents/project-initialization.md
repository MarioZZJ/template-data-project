# 项目初始化流程

初始化不是只把 `.venv` 建好。
一个 agent 友好的科研项目还需要先形成足够明确的研究上下文。

## 推荐顺序

1. 运行 `make init` 配置 Python 环境。
2. 运行 `make init-tex` 检查 TeX 环境。
3. 在 @docs/plans/research-plan.md 写研究计划草案。
4. 在 @docs/project-preferences.md 写环境、工具和操作偏好。
5. 根据计划拆出第一个最小实验目录。
6. 更新 @DASHBOARD.md。

## 研究计划草案要回答什么

- 研究问题是什么。
- 当前已知数据源是什么。
- 第一版方法或分析思路是什么。
- 第一项可运行实验是什么。
- 什么结果算“足够进入下一步”。
- 当前还不知道什么。

不要求一次性写完整路线图。
先让计划足够支持第一个可运行实验。

## 环境和操作偏好要回答什么

- Python、TeX、数据库、API、GPU 或远端机器如何使用。
- 大文件和敏感凭据如何处理。
- 常用命令是什么。
- 哪些操作需要先确认。
- 输出文件默认放在哪里。

## Agent 接手规则

- 先读 @DASHBOARD.md。
- 当前任务涉及计划时读 @docs/plans/research-plan.md。
- 当前任务涉及环境或运行方式时读 @docs/project-preferences.md。
- 只打开当前实验对应目录，不预读无关实验。
