# 写作和绘图风格

这是 agent 文档，不是 Codex skill。

本文件可以参考 Nature 风格科学写作原则，但项目内的权威判断写在这里。
如果项目后来引入 Nature-style skill 或原文参考，可以从本文件或 `AGENTS.md` 链接过去。
模板阶段不要为了写作风格创建 skill，除非已经有真实可复用的工作流。

## 科学写作

- 一句话只表达一个 claim。
- 尽量先给证据，再给解释。
- 区分观察、推断和猜测。
- 避免夸张的新颖性表述。
- 避免没有证据的因果语言。
- 优先使用具体名词和主动动词。
- TeX 正文保持一行一句。

## 图表

- 先明确图回答的科学问题。
- 坐标轴、单位、图例和面板标签要能独立阅读。
- 线图和示意图优先输出矢量格式。
- 必须用位图时使用高分辨率输出。
- 配色优先可读性和可访问性。
- 不要 chartjunk。
- 通用图输出到 `outputs/figures/`。
- 手稿专用图输出到 `docs/writing/manuscript/figures/`。
- 图表成为项目证据时，在 @DASHBOARD.md 记录来源脚本和数据源。

## 图注

好的图注应说明：

1. 图里展示了什么。
2. 如何测量或计算。
3. 关键比较是什么。
4. 主要发现是什么。
5. 必要的限制和注意事项。
