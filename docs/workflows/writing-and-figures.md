# 写作与图表

## 科学表述

- 一句话表达一个主要判断，先给证据，再解释。
- 区分直接观察、模型估计、研究者推论和不确定性；没有设计支持时不使用因果语言。
- 不夸大新颖性、泛化范围或预测性能；零结果和相反结果如实呈现，预设与探索性分析分开。
- 每项阶段成果说明它服务哪个论证、需要什么后续证据；方法或样本改变时重查受影响的正文和图表。
- TeX 正文一行一句，段落间空行。

## 数据图与解释图

实证统计图必须从真实数据和确定的绘图代码生成。图回答明确问题，表呈现可复核数值；坐标轴、单位、样本量、图例、面板标签及不确定性可独立阅读。优先适合出版的矢量格式，位图明确分辨率，配色兼顾色觉可访问性。

概念关系、决策比较或阶段进展可使用已在运行时验证的 imagegen，并参考共享研究汇报技能的构图。先核对内容卡，生成后核对数字、单位、否定词和方向，最多一次针对性修正。生成图不能制造统计证据；评论始终保留结论和待决定事项。工具缺失不静默改用新付费 API；HTML 仅用于确需交互或大量明细的交付。

## 正式成果选择

运行产物先保存在外部 `runs/<运行编号>/outputs/`。检查科学含义、来源和呈现后，才用 `export` 选入 Git 中 `outputs/figures/` 或 `outputs/tables/` 并维护 `outputs/provenance.json`。文件采用稳定语义名称，不使用 `final`、`latest` 等后缀。

图注和表注说明展示内容、计算方式、关键比较、样本与不确定性、主要观察和必要限制，不加入证据不支持的新结论。手稿与实验只链接中央正式产物，不各自复制图表。

正式图表变化时检查来源索引、实验解释、正文和图注、工作流触发路径；任务状态仍由 Multica 维护，看板按需重新生成。
