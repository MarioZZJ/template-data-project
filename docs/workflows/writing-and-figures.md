# 写作与图表

## 科学写作

- 一句话只表达一个主要判断，先给证据，再给解释。
- 区分直接观察、模型估计、研究者推论和不确定性。
- 没有设计或证据支持时不用因果语言。
- 避免夸大新颖性、泛化范围或预测性能。
- TeX 正文保持一行一句，段落之间空一行。

## 正式图表

- 图回答明确的研究问题，表呈现可复核的数值。
- 坐标轴、单位、样本量、图例和面板标签应能独立阅读。
- 优先使用适合出版的矢量格式；使用位图时明确分辨率。
- 配色兼顾可读性和色觉可访问性。
- 文件使用稳定语义名称，不使用 `final`、`latest` 等后缀。

`outputs/figures/` 和 `outputs/tables/` 是正式图表唯一真源。
图表必须能追溯到生成源码、输入数据和关键参数；手稿只引用中央输出，不保存副本。

## 图注和表注

图注或表注说明：展示内容、计算方式、关键比较、样本或不确定性、主要观察及必要限制。
不要在图注中加入图表无法支持的新结论。

## 变更同步

正式图表变化时检查 `DASHBOARD.md`、相关实验 README、手稿正文与 GitHub workflow 路径触发条件。
