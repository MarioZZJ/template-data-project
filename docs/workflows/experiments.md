# 实验工作流

## 何时建立实验

一个实验目录对应一个研究假设、方法比较、稳健性问题或阶段性研究问题，不对应一次普通程序运行。
推荐路径为 `experiments/001-<slug>/README.md`。

## 实验 README 最小内容

- 问题或假设；
- 数据来源、版本和分析样本；
- 相关 `src/` 脚本；
- 参数、随机种子和运行命令；
- 当前观察及其证据边界；
- 决策和下一步；
- 正式输出链接。

## 执行规则

1. 先确认研究计划和依赖数据足以支持实验。
2. 明确比较、指标和完成标准。
3. 运行根 README 中对应步骤并保留可复现参数。
4. 区分观察、研究者推论和仍待验证的解释。
5. 状态变化时更新 `DASHBOARD.md`。

实验目录不建立 `results/`。
正式结果只进入 `outputs/figures/` 和 `outputs/tables/`，实验 README 用链接引用。
