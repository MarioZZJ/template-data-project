# Titanic 生存关联分析研究计划

## 研究问题

乘客的性别、舱位、年龄和家庭同行结构，与其生存概率之间存在怎样的关联？

## 研究对象与分析单位

研究对象是 Kaggle Titanic competition 提供的 `train.csv` 中具有 `Survived` 标签的乘客。
分析单位是乘客；`PassengerId` 应为唯一键。

## 项目边界

- 包含：数据质量审计、家庭同行变量构造、描述性统计、分组生存率、Logistic 回归、年龄缺失敏感性、简单诊断和分层交叉验证。
- 不包含：因果效应识别、Kaggle 排名优化、使用 `test.csv` 评价模型或向 Kaggle 提交预测。

## 数据与识别范围

数据来自官方 Titanic competition 的 `train.csv` 和 `test.csv`，详情登记在 `docs/data-sources.md`。
`test.csv` 没有生存标签，只用于展示官方数据获取和结构兼容性。
观测数据与有限变量只支持条件关联描述，不能排除未观测混杂、选择过程或历史数据记录误差。

## 变量与预期方法

- 结果变量：`Survived`。
- 主要解释变量：`Sex`、`Pclass`、`Age`、`FamilySize = SibSp + Parch + 1`，以及由家庭规模推导的 `TravelAlone`。
- 调整变量：可用且有明确解释的 `Fare` 和 `Embarked`，最终模型式在分析脚本中固定。
- 年龄缺失：主分析使用训练折内中位数填补并保留缺失指示；敏感性分析使用完整年龄样本。
- 估计：Logistic 回归的系数、优势比、95% 置信区间与必要统计量。
- 诊断：共线性指标或影响点检查，以及校准或拟合检查。
- 轻量预测验证：`train.csv` 内固定随机种子的分层交叉验证，报告 ROC AUC 和 Brier score，不解释为竞赛排名。

## 主要证据与完成标准

- 原始文件大小和 SHA-256 已记录，且未进入 Git。
- 数据质量检查覆盖行列数、唯一键、类型、缺失、重复和合理范围。
- 描述性结果按四类主要特征展示生存率。
- 主要模型与年龄缺失敏感性能够重建并清楚区分。
- 两张正式图、描述统计表、回归表和性能汇总由编号源码生成。
- 根 README 命令可逐项重跑，`DASHBOARD.md` 与实际状态一致。

## 第一项可执行任务

- ID：`DATA-001`。
- 输入：Kaggle competition `titanic`、已接受规则的用户账户和本机认证状态。
- 方法：列出竞赛文件，分别下载 `train.csv` 与 `test.csv`，拒绝无条件覆盖。
- 输出：`data/raw/titanic/train.csv`、`data/raw/titanic/test.csv` 及 README 中的文件大小与 SHA-256。
- 完成标准：两份文件存在、可读、被 `.gitignore` 忽略且未被 Git 跟踪。

## 风险、限制与当前未知

- 当前尚未通过命令确认账户已接受竞赛规则和 Kaggle 认证可用。
- 年龄缺失机制未知，主分析与完整案例结果可能不同。
- 舱位、票价和登船港口可能反映未观测社会经济与空间位置差异。
- 数据源许可适用范围以 Kaggle competition 页面与用户已接受规则为准。
