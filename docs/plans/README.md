# 研究计划

## 本目录职责

`docs/plans/` 保存研究问题、研究设计、证据标准、风险和重大计划修订。
计划解释为什么做和什么证据足够，不替代根 README 的实际执行命令或 `DASHBOARD.md` 的当前状态。

## 初始化时需要判断

- 研究问题、对象、分析单位和项目边界。
- 数据能支持的识别范围与不能支持的结论。
- 预期方法、比较对象和主要证据标准。
- 第一项依赖已满足、可以执行的任务。

## 推荐建立的项目文件

- 默认维护 `research-plan.md`。
- 只有重大子研究或预注册需求出现时，才增加新的计划文件。

## 当前项目配置

当前只维护 `research-plan.md`，覆盖 Titanic 生存关联研究问题、变量、方法、完成标准、限制和决策记录。
项目状态仍只在 `DASHBOARD.md` 更新。

## 维护规则

- 研究问题、识别范围或证据标准变化时更新计划并记录依据。
- 当前执行状态只写入 `DASHBOARD.md`。
- 完整命令、输入和输出只维护在根 README 的执行顺序中。
- 不把尚未决定的研究路线写成既定事实。
