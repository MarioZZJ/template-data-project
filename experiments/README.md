# 实验与研究解释

一个实验目录对应研究假设、方法比较、稳健性或阶段性研究问题，不对应一次普通程序运行。确有科学问题时建立 `experiments/001-<slug>/README.md`，模板不预建空实验。

## 最小记录

- **问题与预设比较：** 研究判断、方法选择、主要指标和充分证据标准。
- **数据与样本：** 固定来源版本、分析单位、排除与缺失处理，链接来源登记。
- **实施证据：** 对应 issue、脚本和运行编号；实际命令、参数及完整日志留在运行记录。确有需要时保存稳定参数配置。
- **实际观察：** 关键估计、样本量、诊断与不确定性，区分完整分析和试算。
- **解释边界：** 直接观察、估计、研究者推论和仍待验证解释分别陈述；有效零结果或相反结果照常保留。
- **决定与下游影响：** 对问题、样本、方法、后续任务或论文论证有何影响，何时、依据什么作出决定。
- **成果呈现：** 选定图表及其论证用途；正式图表链接至 `outputs/` 及来源索引，候选产物链接相应运行。

## 执行与维护

先确认计划、输入和授权，按 Multica 中当前就绪任务实施。科学解释进入本目录；实时任务状态由平台维护，看板由程序生成。实验 README 不复制状态表或完整运行日志，不建立 `results/` 副本。

研究结论变化时保留原证据语境、变更理由和受影响范围；不能以最新结果覆盖过去决定。普通恢复写运行记录，具有研究意义的经验写回本实验或已有工作流；稳定且可复用的项目流程再提炼为本地技能。

参见 [研究计划](../docs/plans/research-plan.md)、[研究执行](../docs/workflows/research-execution.md)、[正式输出](../outputs/README.md)。
